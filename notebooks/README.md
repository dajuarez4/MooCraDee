# Planetary Crater Segmentation (PCS) Notebooks

This folder contains reproducible Google Colab notebooks for running PCS.

## Available notebooks

- `PCS_GPU_Demo.ipynb`: GPU-enabled Colab demo for running the PCS crater-candidate detection pipeline.

The notebook is designed to:
- check GPU availability,
- install dependencies,
- load the PCS repository,
- use an example Mercury image or upload a custom image,
- run crater-candidate detection,
- visualize results,
- export detections as image and CSV.
